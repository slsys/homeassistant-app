# SLS для Home Assistant OS

Приложение для обнаружения и обслуживания SLS-контроллеров через интерфейс
Home Assistant. Поддерживаемые архитектуры: ARM64 (`aarch64`) и x86-64 (`amd64`).
Версия 0.1.9 имеет статус experimental. Чтение кэша и MQTT проверены на реальном SLS
с прошивкой 2026.09.14d1. Живой лог использует только WebSocket 80/ws. Поддержка обеих архитектур требует дополнительной проверки.

## Возможности

- Обнаружение контроллеров через UDP LocalLink и MQTT-брокер HA.
- Несколько контроллеров, аптайм, время последних данных и отметка LocalLink.
- Перезагрузка по HTTP или MQTT, включая удалённые контроллеры.
- Лог с миллисекундами, очисткой и обновлением через 80/ws.
- Автоматическая установка SVG в боковом меню HA и логотип в списке приложений.
- Открытие и закрытие сопряжения Zigbee с таймером.
- Настройка MQTT и Home Assistant Discovery на SLS.
- Диагностика MQTT и просмотр лога контроллера.
- Русский интерфейс через Home Assistant Ingress, доступный с телефона.
- Светлая и тёмная темы с автовыбором по HA и ручным переключением.
- Тип платы и отдельные поля IP, MAC и прошивки в LocalLink.

Сущности устройств создаёт стандартная интеграция MQTT в Home Assistant.
Для установки SLS HACS не требуется.

## Установка через репозиторий

1. В Home Assistant откройте **Настройки → Приложения → Установить приложение
   → ⋮ → Репозитории**.
2. Добавьте адрес [репозитория SLS](https://github.com/slsys/sls-ha-app):
   `https://github.com/slsys/sls-ha-app`.
3. Выберите **SLS → Установить**.
4. Включите запуск при загрузке и отображение в боковой панели, запустите
   приложение и нажмите **Открыть веб-интерфейс**.

## Локальная установка

1. Через Samba или SSH скопируйте папку `sls_manager` целиком в `/addons` на HAOS.
   Итоговый путь файла конфигурации: `/addons/sls_manager/config.yaml`.
2. Откройте **Настройки → Приложения → Установить приложение** и проверьте
   обновления магазина через меню ⋮. При необходимости обновите страницу.
3. В разделе локальных приложений выберите **SLS** и установите его.
   Запустите приложение и откройте веб-интерфейс.

При установке HAOS собирает контейнер из исходников. Для первой установки
нужен доступ HAOS к Docker Hub и npm; зависимости загружаются автоматически.
Готовый образ контейнера в этот проект не включён.

## Подключение контроллеров

Включите LocalLink на SLS и дождитесь появления контроллера в интерфейсе
приложения — обычно это занимает около минуты. Нажмите **Добавить** и введите
данные доступа SLS. Контроллеры из другой сети могут обнаруживаться через MQTT-брокер HA.

Обнаружение использует multicast `224.0.0.50:8881` и зависит от настроек локальной
сети. При изоляции клиентов Wi-Fi или фильтрации multicast оно может не работать.

История версий: [CHANGELOG](sls_manager/CHANGELOG.md).

Удалённые контроллеры, публикующие данные брокеру HA, появляются в таблице с источником MQTT. Кнопка «Добавить» сохраняет их без подключения к HTTP API.

SVG в боковой панели устанавливается автоматически при запуске приложения.
Для этого SLS получает доступ на запись к конфигурации HA и право её проверки и перезапуска.
После первого подключения модуля HA один раз перезапускается; обычные старты SLS
этого не делают.
